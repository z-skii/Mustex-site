What MUSTEX does

MUSTEX lets you select screenshots of a text conversation. The app sends those images to a server function, which asks Claude (made by Anthropic) to analyze the conversation and return a structured verdict — a score, tone signals, flags, and suggested replies. That result is shown to you in the app.

Screenshots

  • Screenshots you select are sent, in memory, from the app to a Supabase Edge Function, and from there to the Anthropic API for analysis.
  • Screenshots are never written to a database or file storage by MUSTEX. They exist only for the duration of that one request and are discarded once the response is returned.
  • Anthropic processes the images to generate the analysis; see Anthropic's privacy policy for how they handle API inputs.

Anonymous device identifier

  • On first launch, the app generates a random identifier and stores it only on your device (it is not tied to your name, email, or Apple account).
  • That identifier is sent to our server to enforce a limit on the number of free analyses per install, and is stored in a database column alongside a usage count — nothing else.

Analytics

MUSTEX sends a small number of product-usage events to PostHog, an analytics provider, using the same anonymous device identifier described above. The events tracked are limited to:

  • app_opened
  • screenshots_submitted (count only)
  • analysis_completed (score, confidence, duration)
  • analysis_failed (reason)
  • safety_hold_shown
  • reply_copied (which reply style)
  • share_initiated / share_completed
  • limit_reached_shown
  • side_swap_used

No screenshot content, no message text, and no names are ever included in these events.

What we don't do

  • No account or sign-in is required, so we never collect your name, email, or phone number.
  • We don't use advertising trackers, and we don't sell or share data with third parties beyond the processors named above (Anthropic for analysis, PostHog for anonymous product analytics, Supabase for hosting the server function and the device counter).

Safety handling

If a conversation appears to involve a minor in a romantic/sexual context, threats of violence, or an active self-harm crisis, MUSTEX skips the normal analysis and shows a brief supportive message instead. This decision happens inside the same one-time request and is not logged or stored separately.
